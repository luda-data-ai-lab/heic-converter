# HEIC Converter 사용자 매뉴얼 (한국어)

[English](manual.en.md)

> 이 매뉴얼은 기능이 추가될 때마다 함께 갱신됩니다. 현재 버전: 0.1.0 (변환 엔진)

## 1. 이 프로그램은
아이폰은 기본 설정에서 사진을 HEIC(HEIF) 형식으로 저장합니다. HEIC Converter는 이 파일을 어디서나 열리는 JPG나 PNG로 바꿔 줍니다. 모든 처리는 PC 안에서만 이루어지고 인터넷을 사용하지 않습니다. **원본 파일은 절대 수정하거나 삭제하지 않습니다.**

## 2. 지원 형식
| 입력 | 출력 |
|---|---|
| `.heic`, `.heif`, `.hif` (대소문자 무관) | `.jpg`, `.png` |

## 3. 변환 옵션
| 옵션 | 기본값 | 설명 |
|---|---|---|
| 출력 형식 | JPG | JPG는 용량이 작고, PNG는 무손실이지만 용량이 큽니다(약 5~10배). |
| JPG 품질 | 92 | 1~100. 95 이상이면 색 정보 손실(크로마 서브샘플링)이 없습니다. |
| 최대 크기 | 원본 유지 | 긴 변을 지정한 px 이하로 줄입니다. 원본보다 크게 늘리지는 않습니다. |
| 메타데이터 | GPS만 삭제 | **유지**: 촬영일·카메라·위치를 모두 유지 / **GPS만 삭제**: 위치 정보만 제거 / **모두 삭제**: EXIF 전부 제거 |
| 색상 프로파일 | 유지 | 아이폰의 Display P3 색감을 그대로 유지합니다. |
| 파일 날짜 | 유지 | 변환된 파일의 수정한 날짜를 원본과 같게 맞춥니다. |

- 사진의 회전 정보는 항상 반영되므로, 변환된 사진은 아이폰에서 보던 방향 그대로 보입니다.
- 투명 영역이 있는 이미지를 JPG로 바꾸면 투명 부분이 흰색으로 채워집니다. PNG는 투명도를 유지합니다.
- 변환 도중 실패하거나 취소해도 깨진 파일이 남지 않습니다.

## 4. 문제 해결
| 증상 | 해결 |
|---|---|
| "cannot read image" | 파일이 손상되었거나 확장자만 `.heic`인 다른 파일입니다. |
