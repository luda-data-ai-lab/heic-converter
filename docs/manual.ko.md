# HEIC Converter 사용자 매뉴얼 (한국어)

[English](manual.en.md)

> 이 매뉴얼은 기능이 추가될 때마다 함께 갱신됩니다. 현재 버전: 0.5.1 (창 GUI · exe · 설치본 · 우클릭 메뉴 · 폴더 일괄 변환)

## 1. 이 프로그램은
아이폰은 기본 설정에서 사진을 HEIC(HEIF) 형식으로 저장합니다. HEIC Converter는 이 파일을 어디서나 열리는 JPG나 PNG로 바꿔 줍니다. 모든 처리는 PC 안에서만 이루어지고 인터넷을 사용하지 않습니다. **원본 파일은 절대 수정하거나 삭제하지 않습니다.**

## 2. 설치와 실행
1. [Releases](https://github.com/luda-data-ai-lab/heic-converter/releases) 페이지에서 최신 버전의 `HEICConverter.exe`를 받습니다. 명령줄이 필요하면 `HEICConverter-cli.exe`도 받습니다. 설치가 필요 없습니다. 바탕화면 등 원하는 곳에 두면 됩니다.
2. 처음 실행할 때 **"Windows의 PC 보호"** 창이 뜰 수 있습니다. 코드 서명이 없는 프로그램이라 뜨는 경고입니다. **추가 정보 → 실행**을 누르세요.
3. 사용 방법은 세 가지입니다.
   - **창에서 변환**: `HEICConverter.exe`를 더블클릭합니다. **폴더 추가**/**파일 추가**를 누르거나 목록 영역에 폴더·사진을 끌어다 놓고, 옵션을 고른 뒤 **변환 시작**을 누릅니다.
   - **아이콘에 끌어다 놓기**: HEIC 사진이 든 폴더나 파일을 `HEICConverter.exe` 아이콘 위에 끌어다 놓으면 창이 열리고, 마지막으로 저장된 옵션으로 바로 변환을 시작합니다.
   - **명령줄**: PowerShell에서 `.\HEICConverter-cli.exe D:\Photos\iPhone`처럼 실행합니다. `--help`로 전체 옵션을 볼 수 있습니다 (6장).
4. 기본 동작: 하위 폴더까지 모두 찾아 **원본 옆에 JPG**(품질 92, GPS 위치 정보 삭제)를 만듭니다.

### 창 화면
| 영역 | 설명 |
|---|---|
| 폴더 추가 / 파일 추가 / 선택 삭제 / 목록 비우기 | 변환할 대상을 관리합니다. 목록 아래에 찾은 HEIC 개수가 표시됩니다. |
| 하위 폴더 포함 | 끄면 선택한 폴더 바로 안의 사진만 변환합니다. |
| 변환 옵션 | 형식, JPG 품질, 최대 크기, 메타데이터, 같은 이름 처리, 저장 위치 (4·5장). PNG를 고르면 품질 칸은 비활성화됩니다. |
| 변환 시작 / 취소 | 취소하면 진행 중인 사진까지만 마치고 멈춥니다. |
| 진행 막대 | 처리한 개수와 남은 시간(추정)을 보여 줍니다. |
| 결과 표 | 파일마다 상태·원본·결과·메시지. 실패는 빨간색으로 표시됩니다. |
| 결과 CSV 저장 / 출력 폴더 열기 | 변환이 끝나면 활성화됩니다. |
| 메뉴 | **파일**: 탐색기 우클릭 메뉴에 추가, 끝내기 · **언어**: 한국어/English 즉시 전환 · **도움말**: 이 매뉴얼, 프로그램 정보 |

옵션과 언어는 `%APPDATA%\HEICConverter\settings.json`에 자동 저장되어 다음 실행 때 그대로 유지됩니다.


### 설치본으로 설치하기 (선택)
- `HEICConverter-Setup-<버전>.exe`를 실행합니다. 관리자 권한 없이 내 계정(`%LOCALAPPDATA%\Programs\HEIC Converter`)에 설치됩니다.
- 시작 메뉴에 **HEIC Converter**가 생깁니다. 바탕화면 아이콘과 탐색기 우클릭 메뉴는 설치 중에 고를 수 있습니다.
- 제거: Windows 설정 → 앱 → HEIC Converter → 제거. 우클릭 메뉴도 함께 지워집니다.

### 탐색기 우클릭 메뉴
- 폴더, 폴더 안 빈 곳, HEIC 사진을 마우스 오른쪽 버튼으로 누르고 **JPG/PNG로 변환 (HEIC Converter)** 메뉴를 고르면, 창이 열리며 마지막 옵션으로 바로 변환합니다.
- Windows 11에서는 **더 많은 옵션 표시**(Shift+F10) 안에 있습니다.
- 사진은 한 장을 선택했을 때만 메뉴가 나옵니다. 여러 장은 폴더째 변환하거나 창에 끌어다 놓으세요.
- 설치하지 않은 exe(포터블)에서는 창의 **파일 → 탐색기 우클릭 메뉴에 추가**로 켜고 끌 수 있습니다. exe를 옮기면 다시 켜 주세요.

## 3. 지원 형식
| 입력 | 출력 |
|---|---|
| `.heic`, `.heif`, `.hif` (대소문자 무관) | `.jpg`, `.png` |

### 아이폰 사진에서 알아 둘 점
- **세로 사진**: 아이폰은 가로로 저장하고 회전 정보만 붙입니다. 변환할 때 실제로 돌려서 저장하므로 어느 뷰어에서나 바르게 보입니다. 최대 크기는 회전한 뒤 긴 변 기준입니다.
- **HDR(10비트) 사진**: JPG/PNG는 8비트로 저장됩니다. 밝기 단계가 조금 줄어들 수 있지만 일반 화면에서는 차이가 거의 없습니다.
- **넓은 색 영역(Display P3)**: 색상 프로파일을 그대로 넣으므로 색이 바래지 않습니다. 프로파일을 지원하지 않는 프로그램에서는 색이 약간 다르게 보일 수 있습니다.
- **여러 장이 든 HEIC**: 대표(기본) 사진 한 장만 변환합니다.
- **Live Photo**: 사진 부분(.HEIC)만 변환하고 동영상(.MOV)은 건너뜁니다.

## 4. 변환 옵션
| 옵션 | 기본값 | 설명 |
|---|---|---|
| 출력 형식 | JPG | JPG는 용량이 작고, PNG는 무손실이지만 용량이 큽니다(약 5~10배). |
| JPG 품질 | 92 | 1~100. 95 이상이면 색 정보 손실(크로마 서브샘플링)이 없습니다. |
| 최대 크기 | 원본 유지 | 긴 변을 지정한 px 이하로 줄입니다. 원본보다 크게 늘리지는 않습니다. |
| 메타데이터 | GPS만 삭제 | **유지**: 촬영일·카메라·위치를 모두 유지 / **GPS만 삭제**: 위치 정보만 제거 / **모두 삭제**: EXIF 전부 제거 |
| 색상 프로파일 | 유지 | 아이폰의 Display P3 색감을 그대로 유지합니다. |
| 파일 날짜 | 유지 | 변환된 파일의 수정한 날짜를 원본과 같게 맞춥니다. |

- 사진의 회전 정보는 항상 반영되므로, 변환된 사진은 아이폰에서 보던 방향 그대로 보입니다.
- 투명 영역이 있는 이미지를 JPG로 바꾸면 투명 부분이 흰색으로 채워집니다. PNG는 투명도를 유지합니다.
- 변환 도중 실패하거나 취소해도 깨진 파일이 남지 않습니다.

## 5. 폴더 일괄 변환
- 하위 폴더까지 모두 찾습니다 (`--no-recursive`로 끌 수 있음). 숨김 폴더·숨김 파일·0바이트 파일은 건너뜁니다.
- Live Photo의 `.MOV`, 편집 정보 `.AAE`, 이미 JPG/PNG인 파일은 변환하지 않고 "그 외 파일"로만 셉니다.
- 여러 장이 동시에 변환됩니다 (기본: CPU 코어 수 − 1, 최대 8, `-j`로 변경).
- **저장 위치**: 기본은 원본 옆입니다. `-o D:\Converted`를 주면 선택한 폴더 이름 아래에 하위 폴더 구조를 그대로 만듭니다 (예: `D:\Photos\2024\a.heic` → `D:\Converted\Photos\2024\a.jpg`).
- **같은 이름 파일** (`--conflict`):
  | 값 | 동작 |
  |---|---|
  | `rename` (기본) | `IMG_1234_1.jpg`처럼 번호를 붙여 새로 만듭니다. |
  | `skip` | 이미 있으면 건너뜁니다. 다시 실행할 때 새 사진만 변환하려면 이 값을 쓰세요. |
  | `overwrite` | 기존 파일을 덮어씁니다. |
  대소문자만 다른 이름(`IMG.HEIC`, `img.heif`)도 같은 이름으로 봅니다.
- **결과 CSV** (`--report D:\result.csv`): 파일마다 상태(ok/skipped/failed), 원본, 결과 경로, 실패 사유, 걸린 시간을 기록합니다. Excel에서 한글이 깨지지 않게 저장됩니다.
- **중단**: 창에서는 **취소** 버튼, 명령줄에서는 `Ctrl+C`를 누르면 진행 중인 파일까지만 마치고 멈춥니다. 깨진 파일은 남지 않습니다.
- **속도(참고)**: 12MP 사진 1,000장 → JPG, 8코어 PC에서 약 50초(메모리 최대 약 1GB). 동시 작업 수는 CPU 코어 수에 맞춰 자동으로 정해집니다(최대 8).

## 6. 명령줄 옵션 (`HEICConverter-cli.exe`)
| 옵션 | 기본값 | 설명 |
|---|---|---|
| `-f`, `--format` | `jpg` | `jpg` 또는 `png` |
| `-q`, `--quality` | `92` | JPG 품질 1~100 |
| `--max-size N` | 없음 | 긴 변을 N px 이하로 축소 |
| `--metadata` | `strip_gps` | `keep` / `strip_gps` / `strip_all` |
| `-o`, `--out` | 원본 옆 | 출력 폴더 |
| `--conflict` | `rename` | `rename` / `skip` / `overwrite` |
| `--no-recursive` | | 하위 폴더 제외 |
| `-j`, `--workers` | 코어 − 1 | 동시 변환 개수 |
| `--report 파일.csv` | | 결과 CSV 저장 |
| `--lang` | 시스템 언어 | `ko` / `en` |
| `--no-pause` | | 끝난 뒤 Enter를 기다리지 않음 (배치 파일용) |

종료 코드: 0 = 모두 성공, 1 = 실패한 파일이 있거나 변환할 파일이 없음, 2 = 입력을 지정하지 않음.

## 7. 문제 해결
| 증상 | 해결 |
|---|---|
| "cannot read image" | 파일이 손상되었거나 확장자만 `.heic`인 다른 파일입니다. |
| CLI 창이 사용법만 보여 줌 | `HEICConverter-cli.exe`는 폴더를 지정해야 합니다. 창으로 쓰려면 `HEICConverter.exe`를 실행하세요. |
| 한글 경로 | 지원합니다. 경로에 공백이 있어도 됩니다. |
| 색이 원본보다 흐려 보임 | 보는 프로그램이 색상 프로파일을 무시하는 경우입니다. Windows 사진 앱이나 웹 브라우저로 확인하세요. |
| 백신이 exe를 막음 | 코드 서명이 없는 exe라 오진될 수 있습니다. Releases에서 받은 파일인지 확인한 뒤 예외로 등록하세요. |
